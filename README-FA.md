# پی‌استودیو — طراح بصری قالب‌های انکی

نسخه ۱، برنامهٔ PWA بدون نیاز به سرور برنامه‌نویسی یا حساب کاربری.

## فایل‌ها و راه‌اندازی

- `index.html`: رابط اصلی برنامه
- `styles.css`: ظاهر برنامه
- `templates.js`: مجموعه ۱۵ قالب آماده
- `app.js`: سازنده، پیش‌نمایش، ذخیره، خروجی و جایگزین‌سازی
- `manifest.webmanifest` و `service-worker.js`: نصب PWA و کار آفلاین
- `icon.svg` / `icon-192.png` / `icon-512.png`: آیکون‌ها

**نسخهٔ قابل نصب:** همهٔ فایل‌ها را در یک پوشه روی میزبان استاتیک HTTPS مثل GitHub Pages یا Netlify قرار بده؛ آدرس `index.html` را در مرورگر باز کن؛ سپس از گزینهٔ «نصب برنامه» / «افزودن به صفحه اصلی» استفاده کن. پس از بارگذاری و فعال‌شدن Service Worker، فایل‌های برنامه برای استفاده آفلاین کش می‌شوند.

**آزمایش سریع بدون هاست:** فایل جداگانهٔ `pi-studio-standalone.html` را در یک مرورگر باز کن. این فایل به نصب PWA نیاز ندارد، اما برای نصب به‌عنوان PWA باید نسخهٔ چندفایلی را روی HTTPS قرار بدهی. بعضی مرورگرها ذخیره‌سازی یا نمایش فایل‌های محلی را محدود می‌کنند.

## چگونه متن‌های داخل کد به ورودی تبدیل می‌شوند؟

در پروژهٔ «قالب اختصاصی»، کد HTML و CSS و JavaScript را در زبانه‌های جداگانه وارد کن. اگر بخشی از کد شکل زیر داشته باشد:

```html
<div> 01 </div>
<p> 02 </p>
<strong> 01 </strong>
```

برنامه دو ورودی با شماره‌های `01` و `02` می‌سازد. هر دو مورد ` 01 ` از یک مقدار استفاده می‌کنند. **شرط:** عدد دست‌کم دو رقمی باشد و قبل و بعدش یک فاصلهٔ معمولی (`U+0020`) وجود داشته باشد؛ متن `x01` یا `01,` یا `01` چسبیده به `>` تشخیص داده نمی‌شود. جایگزینی به همان روش در CSS و JavaScript هم انجام می‌شود. برای حفظ رفتار JS، متن JS سفارشی به‌صورت محافظه‌کارانه خروجی داده می‌شود. محتوا را در قالب پیش‌نمایش تست کن.

در HTML، گزینهٔ «امن‌سازی متن» روشن است تا `<` و `&` داخل ورودی به متن تبدیل شود؛ در صورت نیاز به واردکردن HTML واقعی می‌توان آن را خاموش کرد. HTML یا JS دلخواهِ ناشناس را اجرا نکن.

## انتقال کد به انکی

- **HTML:** داخل فیلد Note یا محل نمایش فیلد در کارت.
- **CSS:** داخل `Cards → Styling`.
- **JavaScript:** داخل `Front Template` یا `Back Template` پس از محل نمایش HTML. در بعضی نسخه‌ها `<script>` داخل فیلد حذف می‌شود.

هر پروژه شناسهٔ CSS اختصاصی دارد. فایل‌های خروجی در بخش «خروجی کد» قابل کپی یا دانلود هستند. دکمهٔ «ویرایش مستقیم کد» یک نسخه اختصاصی از سه خروجی می‌سازد.

## ذخیره و بازیابی

پروژه‌ها در ذخیره‌سازی محلی همین مرورگر ذخیره می‌شوند (هر پروژه شامل نام، تنظیمات، کد خام و آخرین HTML/CSS/JS ساخته‌شده است). امکان تغییر نام، تکثیر، حذف و پشتیبان‌گیری JSON وجود دارد. ذخیره‌سازی محلی بین دستگاه‌ها به‌طور خودکار همگام نمی‌شود. اگر مرورگر پاک یا عوض شود، برای بازیابی از فایل پشتیبان JSON استفاده کن.

## محدودیت‌ها

- این نسخه به سرویس خارجی یا حساب آنلاین متصل نیست.
- برای نصب PWA به HTTPS یا localhost نیاز است؛ بازکردن یک فایل HTML محلی به‌تنهایی نصب PWA را فعال نمی‌کند.
- پیش‌نمایش JavaScript سفارشی در iframe محدود انجام می‌شود. امنیت و سازگاری کدهای ناشناس را نمی‌توان تضمین کرد.
- CSS فشرده‌سازی محتاطانه دارد؛ HTML و JS سفارشی عمدتاً بدون حذف محتوای معنی‌دار نگه داشته می‌شوند. این انتخاب برای حفظ نتیجهٔ کارت است.
- عملکرد دقیق JavaScript در نسخه‌ها و WebViewهای مختلف انکی باید روی دستگاه نهایی آزمایش شود.
